# Changelog

## 1.0.1

The first release as a driver-only repository:

- `INTEGRATION.md`, a step-by-step guide for people and coding agents;
- `selfcheck.py`, a read-only check of the integration;
- the compiled driver as a release asset;
- the Apache License, Version 2.0, with a `NOTICE` file;
- `CITATION.cff`, with the DOI 10.5281/zenodo.23993707.

The driver code is that of the earlier repositories, unchanged apart from its version number.
